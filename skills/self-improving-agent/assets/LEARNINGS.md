# 学习记录

开发过程中捕获的纠正、洞察和知识空白。

**分类**: correction | insight | knowledge_gap | best_practice
**领域**: frontend | backend | infra | tests | docs | config
**状态**: pending | in_progress | resolved | wont_fix | promoted | promoted_to_skill

## 状态定义

| 状态 | 含义 |
|------|------|
| `pending` | 尚未处理 |
| `in_progress` | 正在处理中 |
| `resolved` | 问题已修复或知识已整合 |
| `wont_fix` | 决定不处理（原因见解决方案） |
| `promoted` | 已提升到 CLAUDE.md |
| `promoted_to_skill` | 已提取为可复用技能 |

## 技能提取字段

当学习记录被提升为技能时，添加以下字段：

```markdown
**状态**: promoted_to_skill
**技能路径**: skills/skill-name
```
